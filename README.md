# HelloHacksWorkshop2026

This is the starter version of the Hello Hacks Workshop. We've created folders for the backend code and the frontend code that you can start with. 

Instructions to run: *Must be using a Node version >18 (check with `node -v`)*
1. Clone the repo
2. In the `pokemon-assistant-react-app` directory, run `npm i`
3. In the `backend` directory, run `npm i`
4. Run the backend with `npx nodemon server.js`
5. Run the frontend with `npm run dev`
6. Follow the link provided in the terminal
